# COMPASS review — distilled learnings

- A SessionStart-loaded file can carry a dangling reference for weeks unseen: COMPASS-MINI.md:65 pointed at 5 modules deleted in the v2.1→v3.0 trim, loaded every session, noticed by no one. Rule: when removing a doc/module, grep every auto-loaded file for its name before considering the removal done. (verified 2026-06-15, find returned zero of the 5 modules)
- The right response to "the model got more capable" is not "add agentic rules to the canon"; it is "check whether each new discipline already loads elsewhere (CLAUDE.md, crank, bet-weights) and reference it instead of duplicating." Only a rule that fires every session AND is written nowhere else earns canon space. (the agent-as-injection-target rule was the only one of 5 candidates that passed this bar)
- Deleting a file orphans every reference to it: removing LIMITATIONS.md and INSTALL-UNIVERSAL.md silently broke README.md's live file table, which a reviewer had marked "KEEP/clean" before the deletion happened. Rule: after deleting a doc, grep the surviving files for its basename and fix referrers in the same pass; a pre-deletion "clean" verdict does not survive the deletion. (caught by post-edit grep, 2026-06-15)
